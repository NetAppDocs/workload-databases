=== Database configurations included in well-architected dashboard

The well-architected dashboard now includes recommendations for your database configurations, allowing you to assess and optimize your setup based on best practices. The first configurations included in the dashboard are: 

* Cold data tiering
* Storage efficiencies
* Snapshot policy
* SSD capacity headroom
* Block device space management
* OS type
* Match block device OS type to host
* Inactive block devices (LUNs)
* Data files (.mdf) placement
* Log files (.ldf) placement
* Multipath I/O status
* Multipath I/O timeout
* Cluster quorum
* Compute rightsizing

Select the main menu in the Workload Factory console, and then select *Well-architected* to find the well-architected dashboard.
